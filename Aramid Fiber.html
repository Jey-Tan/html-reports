主题覆盖率（读表前必看）：1,081 条 1-3★ 中有 345 条（31.9%）命中至少一个差评点，另 736 条（68.1%）未命中任何主题。未命中的绝大多数是「只说差、不说哪里差」的短评（如 "Junk"、"not worth it"、"returned it"），或用了本词典未收录的口语表述。因此各主题的渗透率应理解为下限：缺陷总量只会比主题之和更多，不会更少；第 8 节的原声区可单独筛出这批「未命中」评论逐条核对。

4星级斜率拆分：真缺陷还是使用门槛

星级拆分的读法：每格上行为命中条数、下行为该星级内渗透率（分母是该星级评论总数，已写进表头：1★ 473 / 2★ 298 / 3★ 310 / 4★ 355 / 5★ 1,009）。颜色按百分比绝对大小上色：透明度 = 该格渗透率 ÷ 全表最高渗透率（30.4%），全表同一把尺子，所以「深 = 占比高」，跨行跨星级可以直接比；同一行从 1★ 到 5★ 由深转浅 = 真缺陷，反向变深（或中间高）= 门槛类。真缺陷应从 1★ 往 5★ 单调变浅（清洁头脱落 / 卡扣断裂：30.4% → 27.2% → 15.2% → 6.8% → 1.6%）；门槛类的方向相反，越往高分越厚（「需预热 / 浸水 / 按说明」5★ 1.6%、1★ 2.3%）。各列分母不同，不可横向相加。
